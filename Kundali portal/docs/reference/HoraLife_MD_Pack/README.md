# HoraLife

HoraLife is a modern Vedic Astrology platform focused on authentic calculation, explainable interpretation, multilingual access, and premium reporting.

## Core Areas

- Kundali generation and chart analysis
- Dasha through Mahadasha / Antardasha / Pratyantardasha
- Compatibility
- Yogas / Doshas / Remedies
- Muhurtha and Panchang
- Learning by HoraLife
- Current Life Focus
- Store backend
- Deterministic Prediction Engine
- Premium report synthesis
