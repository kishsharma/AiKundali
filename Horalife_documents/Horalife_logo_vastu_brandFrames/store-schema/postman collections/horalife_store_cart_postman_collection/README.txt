HoraLife Store Cart Postman Collection

1. Import both JSON files into Postman.
2. Select the HoraLife Cart Local environment.
3. Set baseUrl to the running KundaliEngine.Api URL.
4. Set accessToken to a valid JWT without the 'Bearer ' prefix.
5. Run the Cart folder in order.

The collection already includes the Cat's Eye product and variant IDs you tested.
Add Cart Item automatically stores cartId and cartItemId.

To merge with your existing HoraLife API collection, move the imported Cart
folder into HoraLife API > Store, then delete this temporary collection.
