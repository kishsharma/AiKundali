# Resource Handover Checklist

Provide these items to the independent resource:

- [ ] Access to the dedicated source-code repository
- [ ] Development PostgreSQL credentials limited to the `vastu` schema
- [ ] Separate development deployment environment
- [ ] Existing Vastu master manifest / metadata JSON
- [ ] Existing sample floor plan
- [ ] Existing layered-analysis visual reference
- [ ] Small set of HoraLife-approved starter rules
- [ ] Expected observations for the sample plan
- [ ] Approved remedy entries needed by those starter rules
- [ ] HoraLife logo, primary colours and report header/footer guidance
- [ ] Named person for architecture/rule clarifications and acceptance

Do not provide production customer data, production administrator credentials, or direct write access to Kundali/Store schemas.
