# 🔱 AI Kundali Portal

> Modern Vedic Astrology Platform powered by authentic Jyotish principles and AI-assisted interpretation.

---

## Overview

AI Kundali Portal is a comprehensive Vedic Astrology platform designed to generate accurate birth charts, compatibility reports, planetary analysis, yoga detection, dosha evaluation, dasha predictions, and AI-powered personalized insights.

The project combines traditional Jyotish knowledge with modern software engineering to create a scalable, modular, and developer-friendly astrology platform.
